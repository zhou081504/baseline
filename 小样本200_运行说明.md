# 200 个样本的小样本实验

100 正常＋100 信访风险件，抽样种子 42；每个 c 保留全部 s 和原编号。正文未改写，文件不包含 turn_label。

这是重新平衡类别的小样本数据集，指标不能直接与完整数据集指标比较。

所有方法使用同一文件和 seed=42。不要加 --smoke-test，否则会进一步缩成每类每个集合 2 个样本。默认划分约 70%/15%/15%，实际数量见同目录验证文件。

以下命令使用独立的 prepared_small200 和 model_small200 目录。重新实验请更换目录名。尚未自动运行训练。

## CARROT

```bash
ROOT=/root/zzl/baseline
PY="$ROOT/.venv-table/bin/python"
cd "$ROOT/Selection_Retrieval/CARROT"
$PY prepare.py --data "$ROOT/merged_小样本200.xlsx" --max_length 4096 --classifier_max_length 4096 \
  --classifier-model "$ROOT/models/BAAI--bge-m3" --device cuda \
  --output-dir artifacts/prepared_small200
$PY train.py --prepared artifacts/prepared_small200 --output-dir artifacts/model_small200 \
  --classifier-model "$ROOT/models/BAAI--bge-m3" --epochs 2 \
  --device cuda --batch-size 16 --effective-batch-size 64 \
  --gradient-checkpointing --amp bf16
$PY infer.py --model-dir artifacts/model_small200 \
  --split test --device cuda --batch-size 32 --amp bf16
```

## CogLTX
